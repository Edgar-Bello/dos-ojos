# The deck

`Dos_Ojos_demo.pptx`, built by `build_deck.py`, with `overview.png` as its
system diagram.

**It reflects the project as of 17 September 2026.** Three things landed after
it was built and are not in it:

- fields outside the US: NASA POWER weather and SoilGrids soil, chosen per field
  by which side of the border it sits on (a tester in Veracruz runs on these);
- every list of options in a text message is now one choice per line;
- `NOTA` / `NOTE`: the farmer can tell us what no reading can show — half the
  field cut, a corner replanted, a pump out — and it is weighed above every
  reading before the advice is written.

The three package READMEs are always current; the deck is a snapshot.
